Backup e segurança dos dados

Exporte uma cópia JSON para guardar seus cadastros. A importação substitui os dados atuais deste navegador, portanto faça um backup antes.

Importante: este protótipo usa armazenamento local do navegador. As fotos podem ocupar bastante espaço e não são sincronizadas automaticamente com outros aparelhos. Para uso profissional multiusuário, será necessário conectar banco de dados em nuvem, autenticação, armazenamento seguro de fotos e políticas de acesso.

Boas práticas recomendadas

  • Não guardar senha, PIN ou padrão do aparelho na OS.
  • Limitar acesso às fotos e dados dos clientes.
  • Manter registro de alterações e cópias de segurança.
  • Explicar ao cliente a finalidade do registro fotográfico e obter ciência.
  • Não usar este protótipo como único sistema de produção sem testar restauração e segurança.
